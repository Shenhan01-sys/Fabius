## Yang masih terbuka setelah sesi ini

- **Push menunggu kata builder.** Setelah `git fetch`: lokal **1 commit di depan, 188 di belakang**
  `origin/master`, dan **seluruh 188 itu commit data** (`wallet flow` / `snapshot universe`) — nol
  commit non-data. Artinya merge seharusnya bersih (jalur saya tidak menyentuh `universe/`), tapi
  itu belum dijalankan. Per [[Conventions]]: kabari dulu → jalankan
  `python -X utf8 vault/scripts/prepush_check.py` → baru dorong. Yang perlu keputusan builder:
  merge atau rebase di depan, dan apakah 188 commit data itu ikut masuk sebelum dorong.
- **Umur ekor ⑦: segar, bukan berhenti.** Ekor `origin/master` = `94aead6` 2026-09-27T18:21:16Z,
  sedangkan run perintah di atas terjadi pada **2026-09-27T18:58Z** (= 28 Sep 01:58 WIB) — jadi
  perekam berjarak **±37 menit**, bukan sehari. Catatan ini pertama kali menulis sebaliknya ("berhenti, kenapa?") dan
  itu salah simpul: saya membandingkan jam UTC dengan tanggal lokal. Koreksinya ditulis, bukan
  dihapus — lihat [[Concepts/Stale Local Copy]] untuk bentuk kesalahan yang sama.
  Yang masih benar belum terjawab: API GitHub membalas **404** untuk `/actions/runs` tanpa kunci dari
  mesin ini, jadi status run Actions tidak bisa dibuktikan dari repo — perlu builder melihatnya.
- **Mekanika `maker_ledger` (P11)** masih membuat distribusi `|net|` mustahil; tidak satu angka
  whale pun boleh dikutip sampai rem sehatnya lolos ([[TradingKnowledge/Fakta Terukur]] §H).
- **K2 (jalur data historis):** apakah mulai merekam funding + OI per jam (P13) hari ini supaya uji
  carry mungkin suatu saat — ini dibayar kalender, bukan jam-proses. Kelas K2 =
  "jalur ada sekarang, masa lalunya tidak bisa diminta"
  ([[TradingKnowledge/07-Peta-Fabius/GAP4 - Yang Tidak Bisa Diuji Karena Data]]).
