Pemikiran

Ya, tau. Laya adalah model AI open-source (dari Convai Innovations) yang digadang-gadang sebagai saingan/alternatif open-source untuk Jev (dari TypeSafe AI). 

pingax.com

Ringkasan singkatJev: Model “System 1” milik TypeSafe AI (closed-source, API hosted). Dirancang untuk keputusan cepat bertipe tetap (bukan chat/generasi teks panjang), misalnya klasifikasi, routing tiket, triage email, skor urgensi, atau yes/no dengan probabilitas terkalibrasi.
Laya: Jawaban open-source-nya. Dirilis sekitar 18 September 2026 di bawah lisensi Apache 2.0. Bisa dijalankan lokal (self-hosted), gratis per token, dan tersedia di Hugging Face + pip install laya.

Keunggulan utama yang diklaim LayaKecepatan: Sekitar 33 ms (p50 ~32,8 ms) per pertanyaan di GPU T4 (bahkan lebih cepat kalau di-batch). Klaim sekitar 7–8× lebih cepat daripada Jev (yang biasanya 236–276 ms via API).
Arsitektur: Encoder (berbasis ModernBERT-large ~421M parameter untuk versi English, atau mmBERT-base ~322M untuk multilingual yang support 100+ bahasa). Bukan decoder seperti ChatGPT/Claude/Grok yang generate token demi token. Hasilnya langsung berupa jawaban bertipe + probabilitas, jadi minim “hallucination” teks bebas.
Tiga primitif keputusan:choice → pilih satu opsi dari daftar tetap + distribusi probabilitas.
score → skor pada skala ordinal (misalnya tingkat urgensi).
noul → probabilitas yes/no terkalibrasi.

Akurasi (dari klaim resmi & perbandingan pihak ketiga): Di benchmark typed-decisions, Laya (versi fine-tuned) ~76,6% vs Jev ~72,7%. Lebih baik di beberapa task kecil (AG News, emotion), tapi kalah di task dengan banyak label (misalnya Banking77). Kalibrasi (ECE) juga diklaim lebih baik. Catatan penting: angka tinggi biasanya dari checkpoint yang di-fine-tune; zero-shot jauh lebih rendah (mendekati baseline random). 

laya.convaiinnovations.com

Singkatnya, Laya bukan chat LLM biasa — dia spesialis “keputusan cepat & terstruktur” yang ringan, lokal, dan open. Cocok buat agent, guardrail, triage, routing, dll., di mana kamu butuh jawaban bertipe + confidence score tanpa generate teks panjang.Kalau mau coba, cek Hugging Face (convaiinnovations/laya), situs resmi mereka, atau repo GitHub-nya. Ada juga versi multilingual dan yang khusus typed-decisions. Ada yang mau ditanyakan lebih detail (cara install, benchmark, dll.)?

Cara memakai Laya secara freemium / gratis cukup mudah, karena modelnya sepenuhnya open-source (Apache 2.0). Berikut opsi dari yang paling gratis sampai yang ada free tier terbatas:1. Self-host (100% gratis & unlimited – cara terbaik)Ini cara “freemium” sejati: kamu bayar cuma listrik/komputer sendiri, tidak ada biaya per token.Langkah cepat:Install Python 3.10+ (disarankan pakai virtual environment).
Jalankan:bash

pip install laya

Contoh pakai sederhana:python

from laya import Router

router = Router(preload=True)  # preload biar cepat

state = {"body": "Saya ditagih dua kali. Tolong refund."}
questions = {
    "department": {
        "type": "choice",
        "instructions": "Departemen mana yang harus handle?",
        "criteria": {
            "billing": "tagihan, refund, pembayaran",
            "technical": "bug, error sistem"
        }
    },
    "is_urgent": {
        "type": "noul",
        "instructions": "Apakah ini urgent?"
    }
}

result = router.predict(state, questions)
print(result)
